With [Github recently having issues](https://news.ycombinator.com/item?id=44876784) it was a nice time to see what other options folks recommend. I've run [forgejo](https://forgejo.org/) for a little bit but it always feels like a bit too much for solo projects. 

Two new ones mentioned that I haven't seen before were [tangled](https://tangled.sh/) and [Radicle](https://radicle.xyz). tangled seems like a nice integrated model but self hosting the knot is only one piece of the system. Radicle seems like a farther departure from usual forge systems. 

I added a repo to each Radicle and tangled. The tangled story for CI seems nice with Nix based runner. The Radicle system is less developed.
