I recently tried running [OpenLLM](https://github.com/bentoml/OpenLLM) in my homelab. It was super nice to setup and run but pretty poor performance running models on CPU. A [GGUF model](https://huggingface.co/spaces/zhangtao103239/NeuralHermes-2.5-Mistral-7B-GGUF-Chat) on HF was running pretty quickly but OpenLLM doesn't seem to support GGUF.

Running [text-generation-webui](https://github.com/oobabooga/text-generation-webui) with a [Mistral GGUF](https://huggingface.co/TheBloke/Mistral-7B-Instruct-v0.2-GGUF) model has been really nice. The performance on an [AMD Ryzen 3 5300U](https://www.amd.com/en/products/apu/amd-ryzen-3-5300u) is super usable!
