[Diamond MongoDBCollector](https://github.com/BrightcoveOS/Diamond/tree/master/src/collectors/MongoDBCollector)
--------------
A collector for [Diamond](https://github.com/BrightcoveOS/Diamond) that
publishes data from [MongoDB](http://www.mongodb.org) using
[PyMongo](http://api.mongodb.org/python/current/)

[Diamond RabbitMQCollector](https://github.com/BrightcoveOS/Diamond/tree/master/src/collectors/RabbitMQCollector)
--------------
A collector for [Diamond](https://github.com/BrightcoveOS/Diamond) that
publishes data from [RabbitMQ](http://www.rabbitmq.com/) using
[PyRabbit](http://readthedocs.org/projects/pyrabbit/)

[PyJlog Contribution](https://github.com/zxvdr/PyJLog/pull/1)
----------------------
Expose checkpoint information for the [JLog](http://labs.omniti.com/labs/jlog).
Used for reliable publishing to AMQP while reading from
[Ecelerity](http://www.messagesystems.com/index.php).
